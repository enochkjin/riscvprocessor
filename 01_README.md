# riscvprocessor
RISC-V Single Cycle Processor using Verilog HDL

Designed and coded as part of EECS31L (Intro to Digital Logic Lab). Used Verilog to design components of a single-cycle processor and did modular testing
to confirm that everything is in working order. 

The processor takes inputs from the written testbench and runs the inputs through calculations to display the desired outputs, ranging from
AND/OR comparison to basic arithmetic of addition and subtraction.
